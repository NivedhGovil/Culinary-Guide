## Culinary-Guide

This website has descriptions of 3 food items: 
<li> Garlic Butter Pasta</li> <br> 
<li> Caprese Salad </li> <br> 
<li> Stir-Fry with Tofu</li> <br> 

## Features: 
<li> Little JavaScript </li> <br> 
<li> No CSS  </li> <br> 
<li> Only HTML  </li> <br> 

## Features
I have used a progress bar to show the difficulty of each recipe and a dialog box at the end for a bonus link. I also use JavaScript for the dialog box to work. 

## View Website

1. Go here: https://the-culinary-guide.vercel.app/
